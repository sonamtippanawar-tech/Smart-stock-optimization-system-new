STOCKWISE — Premium Smart Inventory & Stock Optimization

FILES
- index.html: application structure and page views
- style.css: responsive professional UI, dark mode, warehouse illustration
- script.js: inventory logic, charts, forecasting, ABC analysis, expiry, suppliers, movements

RUN
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. The app works as a browser-based demo. Internet is required for Chart.js, QRCode.js,
   JsBarcode and Google Fonts CDN assets.

FEATURES
- Overview dashboard and category/stock-health charts
- Product add, edit, delete, search and filters
- Stock-in / stock-out transaction history with stock validation
- Demand estimate using last 30 days of recorded stock-out transactions
- Reorder suggestion with a 20% safety buffer
- ABC inventory classification by cumulative stock value
- Supplier directory and product linking
- Expiry date watchlist
- QR code and barcode generation
- CSV exports, print view, responsive layout and dark mode
- Local browser storage; demo data included

IMPORTANT
This is a front-end demonstration. Data is stored in the current browser using localStorage.
It does not include a production backend, shared multi-user database, or server-side authentication.
Do not use the demo with confidential business data without adding a secure backend and access control.
Forecast outputs are estimates based on the transaction history available in this browser.
